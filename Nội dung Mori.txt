01 - Phân tích nghiệp vụ và thiết kế hệ thống.
1. Dựa vào bản prototype bóc tách ---> danh sách các thực thể (enity) của hệ thống.
2. Dựa vào danh sách thực thể đã được bóc tách ---> vẽ ERD (biểu đồ thể hiện mối quan hệ giữa các thực thể).
4. Thiết kế các API (xác định các endpoint, xác nhận dữ liệu gửi đi, xác nhận dữ liệu trả về, công cụ để biểu diễn và thể hiện API).
5. Xác định kiến trúc phần mềm (Monolithic hoặc Microservices).
6. Lựa chọn công nghệ, công cụ và hệ quản trị cơ sở dữ liệu.
   Back-end: C#, .NET (ASP.NET Core Web API), Entity Framework Core (EF Core)
   Cơ sở dữ liệu: PostgreSQL, PostGIS
   Web Admin: ReactJS
   Mobile: Flutter
